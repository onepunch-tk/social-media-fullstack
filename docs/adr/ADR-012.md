# ADR-012: AGENTS.md 정본 + CLAUDE.md 한 줄 포인터

## Status
Accepted (2026-09-16)

## Context
코딩 에이전트 지시 파일 관례가 AGENTS.md(범용)와 CLAUDE.md(Claude Code)로 갈린다. `create-expo-app`은 기본으로 AGENTS.md/CLAUDE.md/.claude/settings.json을 자동 생성해(`--no-agents-md`로 차단 가능) 프로젝트 규칙과 충돌할 수 있다. 각 step은 격리 세션이라 그 패키지의 규칙을 바로 읽어야 한다(PRD §1.4, F005).

## 결정
- 루트·apps/mobile·apps/api·packages/schemas 4곳에 `AGENTS.md`(구조·명령·규칙의 실체) + `CLAUDE.md`(AGENTS.md를 가리키는 정확히 한 줄)를 둔다.
- 설정 전용 패키지(typescript-config, biome-config)는 루트 AGENTS.md가 설명한다.
- 자동 생성분은 차단하고 프로젝트가 직접 작성한다.
- 루트 AGENTS.md는 마지막 통합 step에서 실측 트리와 동기화한다.

## 이유
- 지시 단일 소스로 드리프트를 막고 도구 중립(AGENTS.md)을 유지하면서 Claude Code 진입점(CLAUDE.md)도 남긴다.
- 패키지별 파일이 격리 세션의 첫 읽기 대상이 된다.

## 트레이드오프
- 4쌍 8파일 유지 비용.
- 구조가 바뀌면 AGENTS.md도 갱신해야 한다(통합 게이트가 검사).
