# ADR-009: Biome 2 단일 lint/format + 공유 config 패키지

## Status
Accepted (2026-09-16)

## Context
사용자가 Biome을 lint & formatter로 지정했다(PRD §1.4). Nest 템플릿은 oxlint+prettier, Expo 템플릿은 `expo lint`(ESLint)를 기본 제공한다. Biome 2.5.13에서 확인된 사항: `linter.rules.recommended`는 deprecated → `rules.preset`; `organizeImports`는 `assist.actions.source.organizeImports`; `files.includes`에 `!!` 강제 제외; npm 패키지에서 `extends`하려면 exports 서브패스(확장자 없는 specifier)가 필요; 워크스페이스 안의 `biome.json` 파일은 중첩 설정으로 스캔되어 `root: false` 없으면 에러; Nest 파라미터 데코레이터는 `unsafeParameterDecoratorsEnabled` 없이는 파싱 에러; `style/useImportType` safe fix가 데코레이터 메타데이터를 파괴.

## 결정
- 루트 `biome.json` 하나가 저장소 전체를 검사한다(`vcs.useIgnoreFile`, 생성물은 `!!`로 제외).
- 공유 규칙은 `packages/biome-config/base.json`(`biome.json`이 아닌 이름)에 두고 `exports {"./biome": "./base.json"}`로 노출하며, 루트가 `extends: ["@social/biome-config/biome"]`로 상속한다.
- 포맷은 space 2·single quote·semicolon.
- `apps/api`에는 `useImportType`을 off.
- eslint/prettier/oxlint은 제거·미도입, 각 패키지 `lint` 스크립트는 `biome check .`.

## 이유
- 한 도구로 lint+format+import 정리 → 격리 세션의 AC가 단순하고 빠르다.
- 공유 패키지는 사용자 선택(turborepo 관례 정렬)이다.
- 파일명·exports 규칙은 Biome 2 문서로 검증된 함정을 회피한다.

## 트레이드오프
- ESLint 생태계 규칙(react-hooks 일부, import 경계 규칙)이 없다 — 레이어 경계는 컨벤션 grep이 맡는다.
- `expo lint` 대체로 Expo 공식 lint 프리셋을 잃는다.
- `useImportType`을 끈 api에서는 `import type` 규율을 사람이 지킨다.
