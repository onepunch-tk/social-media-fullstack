# ADR-007: Expo Router domain-first(`src/app/` 셸 + `src/shared/presentation/` 실체), `web.output: "single"`

## Status
Accepted (2026-09-16)

## Context
Expo SDK 57 기본 템플릿은 이미 `src/app/`, typed routes, React Compiler, `web.output: "static"`을 켠다. `static`은 `expo export --platform web` 시 모든 라우트를 Node에서 프리렌더해 모듈 최상위 부수효과·SSR 미지원 라이브러리에 취약하다. 이 프로젝트는 웹을 타깃하지 않지만(PRD §1.5) `export:web`을 Metro 해석 검증 게이트로 쓴다(PRD F004 edge AC). 템플릿 스캐폴드의 `@/*` 별칭은 크로스 컨텍스트 grep을 우회한다.

## 결정
- `src/app/**`는 named re-export만 두는 라우팅 셸이며, 화면·레이아웃 실체는 `src/shared/presentation/`(도메인이 생기면 `src/{domain}/presentation/`)에 둔다. 루트 레이아웃은 Stack.
- `web.output`을 `"single"`(SPA)로 변경한다.
- 별칭은 `@shared/*`(+`@/assets/*`)만 두고 `@/*`는 제거한다.
- 테스트는 라우트 루트 밖 `__tests__/`에 둔다.

## 이유
- 셸/실체 분리로 화면이 라우트 파일 규약에 묶이지 않고 도메인 슬라이스로 이동 가능하다.
- `single`은 Node 프리렌더를 건너뛰어 FlashList·stylo-native·TanStack Query의 SSR 동작(미검증)에 AC가 좌우되지 않게 한다.
- `@/*` 제거는 컨벤션 grep이 유일한 경계 방어선이기 때문이다(ADR-009).

## 트레이드오프
- 웹 SSG/SEO를 포기한다(비목표).
- 셸 파일이 늘어 라우트마다 두 파일이 된다.
- typed routes 타입은 `expo customize tsconfig.json`이 생성하므로 typecheck 순서 규율이 필요하다.
